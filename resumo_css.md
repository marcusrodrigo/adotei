# Resumo: CSS do ZERO ao Pro - Rafa Ballerini

## 1. Utilidade do CSS e Arquivos Externos
O CSS (Cascading Style Sheets) é responsável pela camada visual de um site. O uso de um arquivo externo (como `style.css`) é o mais recomendado porque separa a estrutura (HTML) da estética (CSS). Isso facilita a manutenção do código, permite que múltiplas páginas compartilhem o mesmo estilo e deixa o projeto muito mais organizado e profissional.

## 2. Glossário de Propriedades
*   **color**: Define a cor da fonte do texto.
*   **background-color**: Define a cor de fundo de um elemento.
*   **margin**: Controla o espaço **externo** de um elemento (afasta um bloco de outro).
*   **padding**: Controla o espaço **interno** de um elemento (afasta o conteúdo da borda do próprio bloco).
*   **display: flex**: Ativa o Flexbox, um modelo de layout que permite alinhar e distribuir elementos de forma fácil e dinâmica.
*   **font-size**: Define o tamanho da letra.
*   **justify-content**: Alinha itens dentro de um container flexível no eixo principal (horizontal).

## 3. O Poder das Classes
As classes são identificadores que usamos no HTML para selecionar elementos específicos no CSS (usando o ponto, ex: `.botao-principal`). Elas ajudam a organizar o código, permitindo aplicar estilos diferentes a elementos da mesma tag ou reutilizar o mesmo estilo em vários lugares sem repetir código.
